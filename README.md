# Relay — AI Customer Support Copilot

Relay is a production-style, full-stack support workspace built as a portfolio project. It combines a working support inbox with customer context, knowledge retrieval, streamed AI-assisted drafting, confidence review, approval controls, analytics and workspace administration.

The project runs immediately with Node.js 18+ and does not require a database, paid API key or npm dependencies.

## Run locally

```bash
npm start
```

Open:

```text
http://localhost:4173
```

For automatic server restarts while editing:

```bash
npm run dev
```

## Persistence

Relay writes local changes to:

```text
data/runtime.json
```

The file is created automatically on first run and is intentionally excluded from version control. Changes remain after restarting the Node server.

Use **Workspace settings → Reset data** to restore the original sample workspace.

## AI implementation

The project intentionally ships with a deterministic local retrieval-and-drafting engine so the complete product can run without credentials. The system still models the important engineering contract used by a hosted AI product:

1. Read the conversation and customer context.
2. Retrieve relevant workspace knowledge.
3. Produce a grounded response and rationale.
4. Stream generation events to the UI.
5. Calculate confidence and surface uncertainty.
6. Require human review before the message is sent.
7. Record the agent's edit, approval or rejection as product-quality feedback.

The generation layer is isolated in `server.js`, so it can later be replaced with an external LLM/vector-search implementation without redesigning the frontend workflow.

## Deployment

Relay listens on `process.env.PORT` when provided, so it can run on a standard Node.js hosting service with:

```text
Build command: none
Start command: npm start
Node version: 18+
```

For a real multi-user deployment, replace `data/runtime.json` with a database and add authentication before exposing the app publicly.
